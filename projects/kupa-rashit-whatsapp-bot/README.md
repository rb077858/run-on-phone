# קופה ראשית – בוט פרקים (ראם בוטים 🤖)

בוט וואטסאפ (Baileys) שרץ על הטלפון באפליקציית **Run on Phone**. הוא שולח את הפרקים של קופה ראשית לקבוצה בוואטסאפ של כל לקוח, דרך החשבון של הלקוח עצמו.

## איך משתמשים (הכל מתוך "ממשק ניהול")
1. **פרקים** ← `+`: מוסיפים קישור לדרייב (שיתוף "כל מי שיש לו את הקישור") או קובץ סרטון מהטלפון.
2. **לקוחות** ← `+`: שם ומספר טלפון, ואז **"חיבור וואטסאפ"**. הלקוח סורק QR, או מזין קוד צימוד שנוצר למספר שלו. אם מתחבר מספר אחר, החיבור מבוטל. אחרי החיבור נוצרת אצלו הקבוצה **"קופה ראשית פרקים"**, עם תיאור, הגדרות נעולות והודעות זמניות כבויות. ההודעה הראשונה בקבוצה היא הודעת הסבר נעוצה: איך מחפשים פרק ואיך מבקשים סרטון שלא נפתח. הנעיצה מתחדשת בסנכרונים, כי וואטסאפ מגבילה נעיצה ל-30 יום.
3. **🔄 סנכרון לכולם** (או סנכרון ללקוח אחד). אחר כך עוצרים את הבוט מהאפליקציה.

## מה קורה בסנכרון
- הבוט בודק שהקבוצה לא שונתה. אם שונו השם, התיאור או התמונה, או שצורפו משתתפים, הוא **חוסם** את הלקוח: מוחק את הסרטונים, מוציא את כולם, מוחק את הקבוצה, ויוצר במקומה קבוצה בשם "נחסמת על ידי ראם בוטים" עם הודעה אחת. **"ביטול חסימה"** בממשק מחזיר את הלקוח.
- הוא מטפל ב**בקשות** של הלקוח (ראו בהמשך).
- הוא מוחק סרטונים של פרקים שנמחקו או השתנו, ושולח את מה שחסר. אין חשיבות לסדר. בכל כיתוב כתוב למשל `ע6פ4 · S06E04`, כדי שיהיה אפשר למצוא פרק בחיפוש של וואטסאפ.
- פרק שגדול מדי לוואטסאפ (HTTP 413) **מחולק לחלקים** בלי קידוד מחדש (`src/mp4split.js`, חיתוך בתמונות מפתח). כל חלק נשלח עם הכיתוב "🧩 חלק 1 מתוך 3", ושלושת החלקים נספרים כפרק אחד.

## לאן הסרטונים הולכים
1. **הטלפון שלך** (`DATA_DIR`): הורדות מדרייב וחלקים נשמרים ב-`cache/`, וקבצים שהעלית ב-`media/`.
2. **שרתי וואטסאפ**: כל סרטון מוצפן ומועלה פעם אחת. ההודעה בקבוצה מחזיקה את המפתח לפענוח.
3. **הטלפון של הלקוח**: הסרטון נשמר אצלו אחרי שהוא מוריד אותו מוואטסאפ.

Firebase מחזיק רק את הקוד של הבוט.

**העלאה אחת לכולם:** אחרי שסרטון הועלה, הבוט שומר את ההפניה אליו ושולח אותה לשאר הלקוחות בלי להעלות שוב. לפני כל שליחה כזאת הוא בודק שוואטסאפ עדיין מחזיקה את הקובץ. אם לא, הוא מעלה אותו מחדש מהטלפון ומוריד שוב מדרייב אם צריך. אפשר לכבות את זה בהגדרות.

**מחיקה מהטלפון:** סרטון נמחק מהטלפון X ימים אחרי השימוש האחרון (ברירת מחדל 3, אפשר לשנות בהגדרות). הלקוח מוריד מוואטסאפ ולא ממך, אז המחיקה לא מפריעה לו. סרטון מדרייב יירד שוב בעצמו כשיצטרכו אותו. קובץ שהעלית נמחק רק אחרי שהועלה לוואטסאפ, ואם יצטרכו אותו שוב אחרי שוואטסאפ מחקה את העותק שלה, תתבקש להעלות אותו מחדש ("העלאה מחדש" בפרק).

## איפוס קבוצה
לקוח ← ⋯ ← **"איפוס הקבוצה"**: הבוט יוצא מהקבוצה הקיימת אצל הלקוח ומוחק אותה, ויוצר קבוצה חדשה וריקה עם הודעת ההסבר. הפרקים נשלחים אליה בסנכרון הבא, בלי להעלות שוב אם וואטסאפ עדיין מחזיקה אותם.

## בקשות מהלקוח
סרטון לא נפתח? הלקוח עושה **"השב"** לסרטון וכותב משהו, או כותב `עונה 6 פרק 4` / `ע6פ4`. בסנכרון הבא ההודעה שלו נמחקת (בקבוצה נשארים רק הסרטונים והודעת ההסבר), והסרטון נשלח שוב: רק החלק שהוא השיב עליו, או כל הפרק. אפשר גם מהממשק: לקוח ← ⋯ ← "שליחה מחדש של פרק".

## פרטים
- הממשק בלי סיסמה ונגיש **רק מהטלפון עצמו** (127.0.0.1). כדי לפתוח אותו לרשת המקומית מגדירים `ALLOW_LAN=1`.
- כדי שהסרטון יתנגן בוואטסאפ הוא צריך להיות MP4 (H.264).
- מחיקה "לכולם" בוואטסאפ עובדת רק כיומיים אחרי השליחה, ולכן הבוט גם מוחק "אצלי". כיוון שבקבוצה נמצא רק הלקוח, ההודעה נעלמת אצלו בכל מקרה.
- Baileys היא ספרייה לא רשמית, ווואטסאפ עלולה לחסום מספרים שמזוהים כאוטומטיים.

## הרצה במחשב
```
npm install
npm start        # http://127.0.0.1:3000/admin
```
פרסום לטלפון: `FIREBASE_PROJECT_ID=run-on-phone node ../../publisher/publish.mjs .` (או עם `service-account.json`, לפי [PROJECT_PROMPT.md](../../PROJECT_PROMPT.md)).
