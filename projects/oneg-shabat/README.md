# בוט עונג שבת

בוט וואטסאפ שעוקב אחרי הסקרים בקבוצת **עונג שבת** ומציג סיכום חי:
- כל 5 דקות (ניתן לשינוי) הוא מסנכרן את הסקרים של היום ומעדכן את הסיכום.
- סקר נוכחות ("מי בא", "באים היום?", "נפגשים היום?"…) קובע מי מגיע, מי אולי ומי לא מגיע. הזיהוי מכיר גם תשובות כמו "כעע", "לט", "נעע", "אוחי", "לא פה שבת" ו"אין לי כח".
- **מי שסימן שלא מגיע: הבחירות שלו בסקרי המיקום והשעה לא נספרות** (הן מוצגות מחוקות).
- ההודעות שהמנהלים כותבים בקבוצה (למשל "בלוקיישן ב22:00") מוצגות בדף.

## דפים
| כתובת | מה יש שם |
|---|---|
| `/` | דף הסיכום: מגיעים / אולי / לא מגיעים / לא ענו, מה מוביל כרגע, וכל סקר עם שמות |
| `/admin` | ממשק ניהול: **רק מהמכשיר שמריץ את הבוט** (127.0.0.1) |
| `https://<project>.web.app/oneg-shabat/` | הקישור הציבורי (Firebase Hosting), מתעדכן בכל סנכרון |

### ממשק הניהול
- חיבור וואטסאפ: סריקת QR או קוד קישור לפי מספר טלפון, וניתוק.
- **עצירה / המשך של הבדיקות**, סנכרון מיידי.
- **סיכום סופי**: נועל את הסיכום של היום כך שלא יתעדכן יותר (ואפשר לבטל את הנעילה).
- בחירת קבוצה (ברירת מחדל: הקבוצה ששמה מכיל "עונג שבת") ובחירת יום (ברירת מחדל: היום, או היום האחרון שיש בו סקרים).
- לכל סקר: סוג (נוכחות / רגיל), הסתרה מהסיכום, ולכל תשובה בסקר נוכחות: מגיע / אולי / לא מגיע.
- לכל אדם: סימון ידני (למשל מי שהודיע בעל-פה) וכינוי שיוצג במקום השם.
- הודעה שמוצגת בראש הדף, הסתרת שמות מהדף הציבורי, וכיבוי הפרסום הציבורי.
- העתקת הסיכום כטקסט לוואטסאפ, או שליחה אליך בפרטי.

## הרצה בטלפון (Run on Phone)
באפליקציה: **הוסף פרויקט** ← הקוד ← **הרצה** ← **ממשק ניהול** ← סורקים את ה-QR מהטלפון שנמצא בקבוצה (וואטסאפ ← מכשירים מקושרים).
הבוט רק קורא. הוא לא כותב בקבוצה.

> הבוט רואה רק סקרים שנשלחו אחרי שחובר (וחלק מההיסטוריה האחרונה שוואטסאפ שולח בחיבור הראשון). כדאי לחבר אותו לפני שישי.

## הרצה במחשב (Windows)
פותחים PowerShell בתיקייה שבה רוצים את הבוט ומריצים:
```powershell
irm https://raw.githubusercontent.com/rb077858/run-on-phone/main/projects/oneg-shabat/pc/install.ps1 | iex
```
נוצרת תיקייה `oneg-shabat`, ובתוכה תיקיית `הפעלה` עם:
- `start.bat`: מפעיל את הבוט ופותח את ממשק הניהול (http://localhost:3000/admin).
- `update.bat`: מוריד את הגרסה האחרונה מהמאגר (הנתונים בתיקייה `data` נשמרים).
- `install.bat`: מתקין Node.js (אם חסר, דרך winget) ואת החבילות.

כדי שגם המחשב יעדכן את הקישור הציבורי: בממשק הניהול בטלפון ← "פרסום ציבורי" ← העתק הגדרות, ומדביקים בממשק הניהול במחשב. כדאי להריץ רק עותק אחד בכל פעם, אחרת שניהם יכתבו לאותו קישור.

## הגדרת Firebase (חד-פעמית, מהסשן של Claude)
```bash
gcloud auth application-default login --no-launch-browser
node projects/oneg-shabat/deploy/setup-firebase.mjs <project-id>
GOOGLE_CLOUD_PROJECT=<project-id> node publisher/publish.mjs projects/oneg-shabat
```
הסקריפט מפעיל התחברות Email/Password, יוצר משתמש Firebase לבוט שמורשה לכתוב רק את `onegShabat/*`, מעדכן ומפרסם את `firestore.rules`, מעלה את הדף ל-Firebase Hosting, וכותב `firebase-writer.json`. הקובץ לא נשמר ב-git (המאגר ציבורי), אבל נארז לטלפון עם הקוד.
עדכון הדף הציבורי בלבד: `--hosting-only`.
