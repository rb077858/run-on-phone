# Run on Phone

אפליקציית אנדרואיד שמריצה פרויקטי Node.js (בוטים לוואטסאפ עם Baileys, שרתים, ממשקי ניהול) **על הטלפון, ברקע, 24/7**: גם אחרי קריסה וגם אחרי הפעלה מחדש של הטלפון.

```
מחשב (סשן Claude Code)               Firebase (Firestore)                 הטלפון
run-on-phone.json + קוד  ──publish──▶  projects/123456  ◀──קוד 6 ספרות──  Run on Phone
                                                                         node 24 ברקע
```

- **Node.js 24 אמיתי** (arm64) בתוך האפליקציה, עם תהליך נפרד לכל פרויקט.
- הוספת פרויקט לפי **קוד בן 6 ספרות**, ועדכון אוטומטי בכל הפעלה.
- כפתורים לכל פרויקט (ממשק ניהול, הרשמה, חיבור וואטסאפ…) שנפתחים בתוך האפליקציה.
- לוגים חיים, הפעלה מחדש אוטומטית אחרי קריסה, והפעלה אוטומטית אחרי ריסטארט.

## התחלה

- הפרומפט להדבקה בסשן Claude Code של פרויקט: [PROJECT_PROMPT.md](PROJECT_PROMPT.md)
- פרויקט לבדיקה: [examples/hello-server](examples/hello-server)

## איך זה עובד
- `tools/fetch-runtime.mjs` מוריד את Node.js מ-Termux ומכין אותו לאנדרואיד: הקבצים נכנסים ל-`jniLibs`, השמות מותאמים, ו-`RUNPATH` מוגדר ל-`$ORIGIN`. Gradle מריץ את הסקריפט אוטומטית בבנייה הראשונה.
- `publisher/publish.mjs` אורז פרויקט (כולל `node_modules` לפרודקשן) ומעלה אותו ל-Firestore בחלקים.
- האפליקציה מורידה את הפרויקט לפי הקוד ומריצה אותו כתהליך `node` שמנוהל על ידי Foreground Service.
